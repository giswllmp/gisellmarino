## Cómo reemplazar el PDF del proyecto de Chupaca sin romper el enlace
1. Corrige el informe.
2. Guarda el nuevo PDF con este nombre exacto:
   `ozono-incendios-chupaca-2023.pdf`
3. Reemplaza el archivo ubicado en:
   `assets/docs/ozono-incendios-chupaca-2023.pdf`

No necesitas editar el HTML si mantienes el mismo nombre.
